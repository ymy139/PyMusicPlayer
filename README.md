# PyMusicPlayer

🎵Simple and beautiful local music player / 简洁美观的本地音乐播放器🎵

## 上手指南

- ~~从Github Release下载最新版，安装，运行~~（暂未发布Release）
- 通过源码编译
  - 克隆本项目至本地
  - 通过`uv sync`安装依赖（若未安装uv，请先安装）
  - 通过`python src/main.py`运行，或通过`pyinstaller -w src/main.py`打包为可执行文件
